# Streamlit UI для просмотра запусков CodeCollector

## Что это

Небольшой интерфейс на Streamlit для просмотра уже выполненных запусков `pipeline generate`.

UI читает файлы `pipeline_run_*.json` из каталога `.runs/` и показывает:
- список запусков;
- общую сводку по выбранному запуску;
- шаги выполнения и тайминги;
- shortlist кандидатов поиска;
- собранный контекст;
- результаты внешней генерации кода и тестов;
- diff, проверки и merge plan.

## Как запустить

```bash
cd /mnt/data/codecollector_ui
streamlit run app.py
```

По умолчанию UI ищет run artifacts в каталоге `.runs` относительно текущей рабочей директории.
Если запустить приложение из каталога проекта `codecollector`, оно сразу увидит локальные run bundles.

## Что уже есть в интерфейсе

- фильтр по проекту;
- фильтр по статусу проверок;
- поиск по `run_id`, `target`, `title`;
- отдельные вкладки:
  - Общее
  - Этапы
  - Поиск
  - Контекст
  - Генерация кода
  - Генерация теста
  - Repair
  - Diff
  - Проверки
  - Merge
  - Raw
