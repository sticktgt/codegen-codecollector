# UI для просмотра запусков CodeCollector

## Что это

Небольшое приложение на Streamlit для просмотра результатов запусков `pipeline generate`.

UI читает файлы `pipeline_run_*.json` из каталога `.runs/` и показывает:
- список запусков;
- сводку по выбранному запуску;
- шаги выполнения и длительности;
- результаты поиска;
- собранный контекст;
- результаты внешней генерации кода, тестов и repair;
- diff, проверки и merge plan;
- метрики использования токенов.

## Как запустить

```bash
cd codecollector_ui
streamlit run app.py
```

По умолчанию UI ищет run artifacts в каталоге `.runs` относительно текущей рабочей директории.
Если запустить приложение из каталога проекта `codecollector`, оно сможет читать локальные run bundles без дополнительной настройки.

## Что показывает интерфейс

### Таблица запусков

В таблице выводятся:
- время запуска;
- проект;
- target;
- статус проверок;
- был ли repair;
- были ли сгенерированы тесты;
- общее число токенов;
- общая длительность.

### Сводка по выбранному запуску

В верхней части страницы показываются:
- проект;
- статус проверок;
- был ли repair;
- количество созданных тестовых файлов;
- длительность;
- общее число токенов;
- число токенов embeddings.

### Вкладки

Интерфейс содержит вкладки:
- Общее
- Этапы
- Поиск
- Контекст
- Генерация кода
- Генерация теста
- Repair
- Diff
- Проверки
- Merge
- Raw

## Метрики токенов

Во вкладке `Общее` показываются:
- токены embeddings;
- токены генерации кода;
- токены генерации теста;
- токены repair;
- общее число токенов по запуску;
- входные и выходные токены LLM;
- число LLM-вызовов;
- число вызовов embeddings.

Вкладки `Генерация кода`, `Генерация теста` и `Repair` также показывают `llm_usage` для соответствующего шага.
